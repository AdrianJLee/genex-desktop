# Building this Godot game

This game is a Godot 4 project: the folder with project.godot. Build it in Godot's own files, never as a web page: scenes (.tscn, Godot's text format) and GDScript (.gd), in the project's folder; res:// is that folder. Keep scenes small and readable: a node per line block, ext_resource for scripts and assets, sub_resource for shapes and materials. Use typed GDScript 4 (var speed: float, func _physics_process(delta: float) -> void), @export for tuning values and Input actions (ui_left, ui_accept or ones you add to project.godot's [input]). When you are unsure of an API, ask godot__class-reference rather than guessing from Godot 3 (no KinematicBody, yield or onready without @). After every change call godot__check and fix each error it names; godot__run-scene plays a scene headless (pressing keys when you give them, e.g. "right 1, space") and answers its prints and runtime errors; godot__screenshot shows you the game at a moment of play, after keys, with an optional short recording: use it to check that controls work, not only that the first frame draws. Fill whatever size the game is shown at, as a web game fills its page: Genex's Live tab and the published page are any size and resize. Keep project.godot's window/stretch/aspect="expand" (never "keep", which adds black bars), place things inside what the camera shows (in 2D, get_canvas_transform().affine_inverse() * get_viewport_rect(); a centred Camera2D shifts it) rather than a fixed 1280×720, and anchor UI to the screen's edges. Keep a Camera3D or Camera2D in the genex_shot group framing what matters: screenshots, save points and the reviewer look through it, 3 seconds into the main scene with no keys pressed. If the game starts on a title screen or needs input to show play, set genex/shot_keys (e.g. "enter 0.2, wait 1") and genex/shot_seconds in project.godot's [genex] section so those pictures show real play. Generated assets (Genex's, Blender's) are delivered into the project under assets/<plugin>/<job>/: load them as res://assets/... paths. To play the game in Genex's web preview or publish it, call godot__web-export: Godot's Web export goes into web/ at the game's root (it is Godot's build: never edit it, export again after changes). For online play or multiplayer, read the godot-multiplayer skill and call godot__multiplayer: Genex's own addon, never npm or a web page. Never edit the .godot folder: it is Godot's cache. The person may have the project open in their own Godot editor, which reloads files you change; don't ask them to close it.
