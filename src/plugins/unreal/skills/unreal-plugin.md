# Shipping this Unreal plugin

This game is an Unreal plugin in unreal/Plugins/<Plugin>/, built inside its host project unreal/<Plugin>Host.uproject. Ship it in this order. 1. unreal__plugin-build (the user confirms; Genex saves their work and quits Unreal, builds, then opens Unreal again). Read unreal__plugin-status while you do other work; fix every error it names and build again until it passes. 2. Write automation tests in the plugin's module under Source/<Plugin>/Private/Tests/ with IMPLEMENT_SIMPLE_AUTOMATION_TEST, each named <Plugin>.<Area>.<Case> and flagged EAutomationTestFlags::EditorContext | EAutomationTestFlags::EngineFilter, guarded by WITH_DEV_AUTOMATION_TESTS; build again. 3. unreal__plugin-test runs them headless; read unreal__plugin-status, fix what fails and run them again. 4. unreal__plugin-package packages the plugin with BuildPlugin; read unreal__plugin-status until it is done. 5. Open the plugin's window in Unreal (its menu entry or toolbar button), then call app_look with app UnrealEditor, window <Plugin> and save unreal/Saved/Genex/Shots/<Plugin>-window.jpg. 6. Call finish with the proof unreal__plugin-status lists: the test summary, the package note and the window's picture. One plugin job runs at a time.

Tools agents call: when the user wants agents to drive the plugin through Unreal's MCP, make it a toolset. Add Epic's ToolsetRegistry plugin to the .uplugin's Plugins and its module to the Build.cs dependencies, write one UToolsetDefinition class per file and register it in StartupModule with UToolsetRegistry::RegisterToolsetClass (unregister it in ShutdownModule). Each tool is a static UFUNCTION(meta = (AICallable)): its doc comment is the description agents read, so say what the tool does and each parameter's meaning and units, nothing the signature already says. Take and return real types (structs, arrays, object pointers), never JSON inside a string; return data, never a status: on failure call UKismetSystemLibrary::RaiseScriptError and return a default value. Pair what can be paired (get and set, create and delete), and leave generic property reads and writes to Epic's ObjectTools. Test each tool's success and each of its errors. A new tool needs unreal__plugin-build: Live Coding doesn't pick up a new UFUNCTION.
